# Atualização — modos e velocidade

- Adicionado controle de velocidade 1x/2x exclusivo do host.
- Velocidade sincronizada via RPC autoritativa.
- Adicionados 6 modos: Clássico, Rápido, Só Rimuru, Infinito, Sobrevivência e Corrida.
- Cada modo possui dinheiro inicial próprio.
- Lobby agora mostra nomes e descrição dos modos.
- Criadas cenas separadas em `cenas/modos/`.
- Infinito aumenta progressivamente a quantidade de inimigos.
- Só Rimuru usa a cena do Rimuru para todos os inimigos.
- Regras de posicionamento de torre continuam validadas também no servidor.
